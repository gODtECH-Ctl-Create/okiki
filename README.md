# Okiki Website

A very simple website made with HTML (HyperText Markup Language) and a little CSS (Cascading Style Sheets).

## Files

- `index.html`: Home, About, Services, and Contact.
- `signup.html`: A demo sign-up form.
- `thank-you.html`: Thank-you page.

## Run it in VS Code

1. Install Git from <https://git-scm.com/download/win> if it is not already installed.
2. Open VS Code and press `Ctrl + Shift + P`.
3. Choose **Git: Clone** and enter:

   ```text
   https://github.com/gODtECH-Ctl-Create/okiki.git
   ```

4. Choose where to save it, then click **Open**.
5. If the website files are not there yet, open **Terminal → New Terminal** and run `git pull origin main`.
6. Install the **Live Server** extension by Ritwick Dey.
7. Open `index.html`, right-click, and choose **Open with Live Server**.

## Test it

Click the menu links, choose **Sign Up**, and submit the demo form to see the thank-you page.

The sign-up form does not create accounts or save details. The contact email in the page is a placeholder. Replace it with your own contact email.
